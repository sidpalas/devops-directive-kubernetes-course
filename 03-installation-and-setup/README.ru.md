# Установка и настройка

> 🌐 [English](README.md) | Русский

## Зависимости

### Docker Desktop

Установите Docker Desktop в соответствии с инструкциями разработчика (установка Docker Desktop на [Mac](https://docs.docker.com/desktop/install/mac-install/), [Windows](https://docs.docker.com/desktop/install/windows-install/) или [Linux](https://docs.docker.com/desktop/install/linux-install/).)

### Devbox

Все остальные программные зависимости курса определены в файлах `devbox.json` и `devbox.lock` в корневой директории.

Установите Devbox согласно инструкциям: https://www.jetify.com/devbox/docs/installing_devbox/

После установки можно выполнить:

```
devbox shell
```

в любом месте репозитория — devbox с помощью пакетного менеджера Nix установит копию всего необходимого программного обеспечения в изолированном окружении.

### Алиасы

Рекомендую создать следующие алиасы:

```
k=kubectl
t=task
tl='task --list-all'
```

### Автодополнение:

Настройка автодополнения по Tab для предпочитаемой оболочки делает жизнь заметно приятнее:

- kubectl: https://kubernetes.io/docs/reference/kubectl/generated/kubectl_completion/
- task: https://taskfile.dev/installation/#setup-completions

## Настройка кластеров

В этой директории содержатся конфигурации и команды для настройки 3 Kubernetes-кластеров. Любой из трёх можно использовать для большинства примеров, за некоторыми исключениями.

### KinD

Запускает Kubernetes-кластер локально внутри Docker! Отлично подходит для целей тестирования и разработки (и не требует никаких дополнительных затрат). Почти все примеры курса можно выполнить в этом кластере, за исключением примеров, демонстрирующих специфичные для облака функции или публикацию сервисов через публичный DNS.

Чтобы запустить кластер, выполните:

```
devbox shell # if you haven't already
task kind:01-generate-config
task kind:02-create-cluster
```

### Civo Cloud

Civo Cloud предлагает простой управляемый Kubernetes-кластер. Их кластеры создаются быстро, а новым пользователям предоставляется кредит на $250 сроком на 1 месяц: https://dashboard.civo.com/signup.

Чтобы создать кластер, выполните:

```
devbox shell # if you haven't already
civo:01-authenticate-cli
civo:04-create-all
civo:05-get-kubeconfig
```

Чтобы удалить кластер, выполните:

```
civo:06-clean-up
```

🚨 ПРИМЕЧАНИЕ: если вы развернули дополнительные ресурсы (например, балансировщики нагрузки), ссылающиеся на VPC/подсети/и т.п., может понадобиться вручную удалить эти ресурсы, чтобы команда завершилась успешно. Также убедитесь, что вы удалили все ресурсы, чтобы избежать нежелательных расходов!

### Google Kubernetes Engine (GKE)

Google управляет Kubernetes-кластерами дольше, чем любой другой облачный провайдер, и отточенность опыта работы с GKE это показывает. Новым пользователям предлагается бесплатный пробный период на 90 дней с кредитом $300: https://cloud.google.com/free.

Чтобы создать кластер, выполните:

```
devbox shell # if you haven't already
gcp:01-init-cli
gcp:07-create-all
gcp:08-connect-to-cluster
```

Чтобы удалить кластер, выполните:

```
gcp:09-clean-up
```

🚨 ПРИМЕЧАНИЕ: если вы развернули дополнительные ресурсы (например, балансировщики нагрузки), ссылающиеся на VPC/подсети/и т.п., может понадобиться вручную удалить эти ресурсы, чтобы команда завершилась успешно. Также убедитесь, что вы удалили все ресурсы, чтобы избежать нежелательных расходов!
