# Встроенные типы ресурсов

> 🌐 [English](README.md) | Русский

Kubernetes предоставляет множество типов ресурсов, покрывающих самые разные потребности при развёртывании и эксплуатации приложений.

Этот раздел охватывает большинство этих типов ресурсов, приводя рабочие примеры для каждого.

## Как пользоваться этим разделом

Каждая директория представляет один тип ресурсов и содержит Taskfile со всеми необходимыми командами.

Задачи снабжены числовыми префиксами, обозначающими правильный порядок их выполнения.

Каждый набор примеров развёртывается в собственный namespace. Это помогает предотвратить конфликты имён и упрощает очистку (поскольку при удалении namespace удаляются и ресурсы внутри него)

```
task 01-create-namespace

### OTHER TASKS

task 07-delete-namespace
```

## Типы ресурсов

🚨 **Примечание:** Следует соблюдать этот порядок (и именно в этом порядке они рассматриваются в видеокурсе)

- **Namespace**: Предоставляет способ разделить ресурсы кластера между несколькими пользователями.
- **Pod**: Самый маленький и простой объект Kubernetes. Представляет собой набор запущенных контейнеров в вашем кластере.
- **ReplicaSet**: Гарантирует, что в любой момент времени запущено указанное количество реплик Pod'ов.
- **Deployment**: Управляет stateless-приложениями, предоставляя такие возможности, как rolling update и откаты.
- **Service**: Определяет логический набор Pod'ов и политику доступа к ним.
- **Job**: Создаёт один или несколько Pod'ов, которые выполняются до завершения.
- **CronJob**: Планирует запуск Job'ов в указанное время или с заданными интервалами.
- **DaemonSet**: Гарантирует запуск копии Pod на всех (или некоторых) узлах кластера.
- **StatefulSet**: Управляет stateful-приложениями, предоставляя гарантии упорядоченности и уникальности Pod'ов.
- **ConfigMap**: Хранит конфигурационные данные, которые могут использоваться Pod'ами.
- **Secret**: Управляет чувствительной информацией, такой как пароли, OAuth-токены и ssh-ключи.
- **Ingress**: Управляет внешним доступом к Service в кластере, как правило, по HTTP.
- **GatewayAPI**: Управляет маршрутизацией трафика внутри кластера, предоставляя расширенные возможности маршрутизации.
- **PersistentVolume и PersistentVolumeClaim**: Управляет постоянным хранилищем для Pod'ов.
- **RBAC (Role-Based Access Control)**: Управляет разрешениями внутри кластера.

### Типы ресурсов вне области рассмотрения

- **LimitRange**: Задаёт ограничения на использование ресурсов внутри namespace.
- **NetworkPolicy**: Контролирует поток сетевого трафика на уровне IP-адресов или портов внутри кластера Kubernetes.
- **MutatingWebhookConfiguration**: Определяет webhook'и, которые могут изменять запросы, поступающие в Kubernetes API server.
- **ValidatingWebhookConfiguration**: Определяет webhook'и, которые могут проверять запросы, поступающие в Kubernetes API server.
- **HorizontalPodAutoscaler**: Автоматически масштабирует количество Pod'ов в Deployment или ReplicaSet на основе наблюдаемой утилизации CPU или других пользовательских метрик.
- **CustomResourceDefinition**: Позволяет пользователям определять собственные типы ресурсов так, чтобы Kubernetes API server мог обрабатывать их (рассматривается в одном из последующих разделов!).
