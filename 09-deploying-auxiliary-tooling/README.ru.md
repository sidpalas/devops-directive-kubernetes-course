# Вспомогательные инструменты

> 🌐 [English](README.md) | Русский

## CloudNativePG (https://cloudnative-pg.io/)

CloudNativePG значительно упрощает развёртывание и эксплуатацию кластеров PostgreSQL на Kubernetes. Как описано в `08-extending-kubernetes`, проект расширяет Kubernetes API с помощью пользовательских ресурсов и кодирует логику, необходимую для управления этими кластерами, в приложение, работающее в кластере.

Показанные примеры содержат как минимальную конфигурацию, так и конфигурацию, которая периодически делает резервные копии базы данных и сохраняет их в объектное хранилище (показаны Google Cloud Storage и объектное хранилище Civo Cloud).

## Trivy Operator (https://aquasecurity.github.io/trivy-operator/latest/)

Trivy Operator автоматически сканирует каждый образ контейнера, запущенный в кластере, и формирует отчёт о CVE и потенциальных последствиях для безопасности других конфигураций кластера/приложений.

Кроме того, он повторно сканирует каждый образ через заданный интервал, что помогает обнаруживать уязвимости, найденные уже после первоначальной сборки образа (например, если сканирование выполнялось в рамках pipeline непрерывной интеграции).

## Cert Manager (https://cert-manager.io/)

Cert Manager предоставляет инструменты для выпуска и управления TLS-сертификатами, которые обеспечивают шифрование трафика к вашему кластеру и сервисам. Он интегрируется с центрами сертификации, такими как Let's Encrypt, и с Ingress Controllers, автоматизируя этот процесс.

В этом репозитории я его не реализовал, но он достаточно распространён и важен, чтобы упомянуть здесь, а его настройка станет отличным упражнением для проверки ваших знаний Kubernetes.
